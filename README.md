# SimiMedi Cooking

Deployable, login-free shared cookbook.

## Current milestone

- Public view mode
- Secret editing link
- Cloud recipe storage through Supabase
- Add, edit, delete and search recipes
- English-first responsive interface

## Supabase setup

Open the Supabase SQL Editor, create a new query, paste the full contents of `database.sql`, and run it once.

## Local preview

Serve this folder over HTTP. Opening `index.html` directly as a `file://` URL may block cloud requests in some browsers.

## Not connected yet

Photo storage, multilingual interface, webpage extraction, screenshot OCR, recipe version history, and GitHub deployment are the next milestones.
